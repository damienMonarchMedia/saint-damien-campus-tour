# Editing and publishing the campus-tour page

Live site: https://damienmonarchmedia.github.io/saint-damien-campus-tour/
Repository: https://github.com/damienMonarchMedia/saint-damien-campus-tour

## Make a small wording change in GitHub

1. Sign in to GitHub and open the repository above.
2. Click `index.html`, then the pencil icon (Edit this file).
3. Find the exact wording you want to change. For example, the location label is `KAPĀLAMA, HAWAIʻI`. Preserve the HTML tags around it.
4. Click **Commit changes…**, enter a short description, and choose **Commit directly to the main branch**. Confirm **Commit changes**.
5. GitHub Pages automatically republishes. Wait a minute or two, then refresh the live site. The repository’s **Actions** tab shows deployment progress; a green check means it finished.

No separate Publish button is needed after each edit. Hosting is configured under **Settings → Pages**, using the `main` branch and `/ (root)` folder.

## Which file changes what?

- `index.html`: headings, paragraphs, links, location labels, and tour embed.
- `style.css`: colors, sizing, spacing, and mobile layout.
- `assets/header-mark.png`: the school wordmark used in the header and footer.
- `crest.png`: the school seal.

For replacement images, open the appropriate folder, choose **Add file → Upload files**, and upload using the same filename to preserve existing links. Review and commit the change.

The location appears in the top bar, footer, hero seal caption, and page description; keep them consistent. Copy and paste accented text to preserve the kahakō in Kapālama and the ʻokina in Hawaiʻi.

Edits made directly on GitHub do not automatically update the copy on your Mac. Keep that local copy in sync before uploading it again, or an old local file could overwrite your newer web edits.
